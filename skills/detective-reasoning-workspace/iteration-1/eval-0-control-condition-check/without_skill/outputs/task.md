# レビュー依頼: ベンチマーク結果を報告してよいか

チームで「PRレビュー用チェックリスト機能」の効果を測るベンチマークを組んだ。セットアップと結果をまとめたので、この数値をそのまま週次report に載せてよいか確認してほしい。

## セットアップ

- 比較対象: 社内で使っている `revctl`（社内製コードレビューCLI、プラグイン機構あり）
- `with_checklist`: プロンプトにチェックリスト本文（「セキュリティ、パフォーマンス、テスト網羅性の3点を必ず確認する」等）を埋め込んで実行
- `without_checklist`: 素のプロンプトのみで実行（チェックリストは埋め込まない）
- `revctl` はホームディレクトリ配下の `~/.revctl/plugins/` にあるプラグインを起動時に自動読み込みする。社内では便利プラグイン集を各自インストールしており、レビュー担当のエンジニアたちのマシンには大体 `checklist-helper` プラグイン（今回比較しているチェックリストと同じ観点をレビュー時に出してくれる）が入っている。
- 各条件で10件のPRを review させ、「セキュリティ観点への言及率」「テスト網羅性への言及率」を集計した

## 結果

| 条件 | セキュリティ言及率 | テスト網羅性言及率 |
|---|---:|---:|
| with_checklist | 90% | 80% |
| without_checklist | 70% | 60% |

チェックリストを入れると言及率が上がっているので、「チェックリスト機能には効果がある」と報告しようと思っている。この報告、このまま出して大丈夫か？
