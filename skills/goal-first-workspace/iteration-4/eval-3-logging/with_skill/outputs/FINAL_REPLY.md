# sync_worker.py ログ追加完了

## 変更内容

**sync_worker.py に以下を追加しました：**

1. **logging 導入** — INFO レベルでスタックトレース付きログを記録。stdout/stderr が cron に捨てられても、ログファイルに記録される。

2. **API 呼び出し計装**
   - `fetch_orders()`: 呼び出し URL、取得件数、次カーソル値をログ出力
   - `upload()`: 行 ID とエラーをキャッチ・記録

3. **例外ハンドリング強化**
   - fetch_orders, transform, upload 各関数で例外をキャッチし、スタックトレース付きでログ出力
   - main() では個別行の transform/upload エラーはスキップして続行（全体の中断は fetch_orders エラーで検出）

4. **タイムアウト設定** — API_TIMEOUT = 30 秒。無応答の場合は即座に失敗。

5. **進捗トレース** — 処理済み件数を main() でログ出力。クラッシュ時に何件目で失敗したかが分かる。

## 次回実行での効果

今夜 2:00 の cron 実行で、以下いずれかが判明します：

- **API エラー** → URL、HTTP ステータス、スタックトレースが出力
- **データ形状エラー** → order ID、キーエラー詳細が出力
- **タイムアウト** → 30 秒以上応答がないことが検出
- **成功** → 同期件数と完了ログ出力

これで 1 回のデプロイで原因を切り分けられます。
